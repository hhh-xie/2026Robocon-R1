本手册完全依据当前固件逻辑整理。三段开关经过程序处理后为位置1、2、3；默认 EdgeTX 未反相时通常对应上、中、下，实际以遥控器通道监视器为准

## 一、操作前安全事项

1. 上电前将摇杆、S1、S2回中，A、D保持释放。
2. 当前固件没有遥控失联超时处理。CRSF通信中断后，最后一次控制值可能继续保留，不能把遥控失联当作急停。
3. 升降传感器限位代码目前被禁用，升降时必须人工观察机械行程。
4. 机械臂自动路径启动后，把B切离位置3不会停止路径；路径仍会在后台继续。
5. B不是全部机构的总模式开关，部分机构会并行响应，尤其是升降和夹爪。

## 二、遥控器通道总表

|通道|控件|当前用途|
|---|---|---|
|CH1|右摇杆X|B=1底盘旋转；B=3机械臂底座|
|CH2|右摇杆Y|B=3机械臂肘部；B=2升降ID6独立微调|
|CH3|左摇杆Y|B=1底盘前后；B=3机械臂肩部；B=2升降ID5独立微调|
|CH4|左摇杆X|B=1底盘横移|
|CH5|A按键|吸取、打开、执行、清空、示教打印|
|CH6|E三段开关|选择吸盘或PE1辅助输出|
|CH7|F三段开关|机械臂任务、DM4310位置、特殊吸盘组合|
|CH8|B三段开关|主模式选择|
|CH9|C三段开关|机械臂高度、夹爪自动位置、Code12发送|
|CH10|S2|升降机构整体运动|
|CH11|D按键|回收、关闭、发送|
|CH12|S1|夹爪3508纵向旋转|
|CH13～CH15|Code12数据|12位数字压缩数据|
|CH16|Code12触发|仅更新内部触发标志，当前未直接触发外部发送|

## 三、B主模式

|B位置|主功能|同时有效的其他功能|
|---|---|---|
|B=1|底盘模式|升降、夹爪、吸盘、PE1、UART4红外|
|B=2|Code12/UART5通信、升降双电机调试|夹爪控制仍有效|
|B=3|机械臂模式|S2整体升降仍有效|

# 四、B=1：底盘模式

## 4.1 底盘操作

|操作|动作|
|---|---|
|左摇杆Y|前进/后退|
|左摇杆X|左右横移|
|右摇杆X|原地旋转|
|三个底盘通道回中|速度清零，并在收到四个电机反馈后进入停车位置保持|

将B切离位置1后，底盘立即清零目标并退出停车保持。

## 4.2 同时有效的机构

B=1时以下机构仍会响应：

- S2：控制两台升降电机同步运动。
- S1：控制夹爪3508纵向旋转。
- F：选择DM4310夹爪平面角度。
- C切入位置2：触发一次夹爪自动对接动作。
- E、A、D：在没有被特殊组合覆盖时控制吸盘或PE1。

## 4.3 B=1特殊组合

|F位置|C位置|功能|
|---|---|---|
|F=2|C=3|特殊吸盘直控：A打开吸盘，D关闭吸盘|
|F=1或3|C=3|进入组合时，通过UART4发送一次Code12红外帧|
|任意|C≠3|根据E开关执行一般辅助控制|

UART4发送只在进入 `B=1、C=3、F≠2` 时执行一次。保持开关不动不会重复发送，必须离开组合后重新进入。

# 五、B=2：通信与升降调试模式

## 5.1 UART5操作

|操作|功能|触发方式|
|---|---|---|
|A按键|UART5发送 `clear\n`|按下沿一次|
|D按键|UART5发送当前12位Code12和换行|按下沿一次|

D发送的数据格式为：

```
000123230123\n
```

共13字节：12个字符 `0～3` 加一个换行符。

## 5.2 升降双电机独立微调

B=2时，S2整体升降被禁用：

|操作|动作|
|---|---|
|左摇杆Y|独立增加/减少升降电机ID5偏移|
|右摇杆Y|独立增加/减少升降电机ID6偏移|

摇杆绝对值超过约400才会动作。

注意：这些独立调试偏移离开B=2后不会清零，会继续叠加在后续升降目标上。

## 5.3 B=2下仍然有效的功能

- 底盘停止。
- 机械臂不接受手动摇杆控制。
- 已启动的机械臂自动路径仍会继续。
- F仍可控制DM4310。
- C=2仍可触发夹爪自动对接。
- S1仍可控制夹爪3508。
- E开关的吸盘/PE1控制被UART5通信分支覆盖，不执行。

# 六、B=3：机械臂模式

切入B=3时，程序会使能三个达妙电机，并记录A、D当前状态。如果切入前已经按住A或D，需要先释放再重新按下。

## 6.1 手动摇杆控制

|摇杆|关节|
|---|---|
|右摇杆X|机械臂底座|
|左摇杆Y|肩部，程序中方向取反|
|右摇杆Y|肘部相对肩部转动，程序中方向取反|
|左摇杆X|未使用|

机械臂为增量位置控制：

- 持续偏转摇杆：目标角度不断变化。
- 摇杆回中：保持当前目标。
- 任一摇杆超过内部死区：立即取消当前自动路径。

## 6.2 F/C/A/D机械臂矩阵

|F|C|A按键|D按键|
|---|---|---|---|
|F=1|C=1|打印当前示教路径点|无|
|F=1|C=2/3|无预设动作|无预设动作|
|F=2|C=1|无预设动作|无预设动作|
|F=2|C=2|执行对接吸取路径并打开吸盘|执行递出路径，吸盘状态不自动改变|
|F=2|C=3|按住时打开吸盘|按住时关闭吸盘|
|F=3|C=1|执行吸取高度3并打开吸盘|执行回收路径，结束后关闭吸盘|
|F=3|C=2|执行吸取高度2并打开吸盘|执行回收路径，结束后关闭吸盘|
|F=3|C=3|执行吸取高度1并打开吸盘|执行回收路径，结束后关闭吸盘|

机械臂高度与C位置顺序相反：

```
C=1 → 高度3
C=2 → 高度2
C=3 → 高度1
```

## 6.3 示教模式

条件：

```
B=3、F=1、C=1
```

操作：

1. 使用机械臂摇杆调整当前位置。
2. 按一下A。
3. USART1调试口输出当前路径点，例如：

```
{-0.095f, -2.020f, 0.145f, 50},
```

A使用按下沿检测，持续按住只打印一次。

## 6.4 对接/递出模式

条件：

```
B=3、F=2、C=2
```

- A按下沿：执行对接吸取路径，并立即打开吸盘。
- D按下沿：执行递出路径，但不会自动关闭吸盘。
- A、D同时按下时，A优先。

## 6.5 方块放置模式

条件：

```
B=3、F=2、C=3
```

- 切换到该组合时，可启动方块放置路径。
- A按住：打开吸盘。
- D按住：关闭吸盘。
- A和D同时按住时，代码先开后关，最终为关闭状态。

如果进入B=3之前F/C已经处于该组合，程序可能只记录当前选择而不立即重新启动路径。切换一次F或C可以产生新的路径选择事件。

## 6.6 自动吸取与回收

条件：

```
B=3、F=3、C选择高度
```

- A按下沿：吸盘先打开，然后机械臂执行选定高度的吸取路径。
- D按下沿：机械臂执行统一回收路径，到达终点后关闭吸盘。
- 代码只根据F/C组合判断D回收是否有效，没有验证机械臂是否真的处于对应吸取位置。

## 6.7 自动路径特性

自动路径内部优先级：

```
人工摇杆取消路径
    > A/D按键启动任务
    > F/C开关切换任务
    > 已启动路径继续
    > 普通摇杆控制
```

其他特性：

- 自动路径每5 ms推进一次。
- 每个路径点到达后默认保持50 ms。
- 吸盘已经自动打开或进入高度回位流程后，保持F=3并切换C，可直接切换高度，无需再按A。
- 离开B=3不会终止已经运行的自动路径。
- 返回B=3后推动任一机械臂摇杆可以取消路径。

## 6.8 B=3下的其他机构

- S2整体升降仍有效。
- S1夹爪3508控制被锁止。
- F对DM4310的普通控制被锁止。
- C=2夹爪自动对接被锁止。
- E开关的普通吸盘/PE1控制不执行。

# 七、升降机构

## 7.1 整体升降

当B不等于2时，S2控制两台升降电机：

|S2状态|动作|
|---|---|
|正方向超过阈值|两台电机同步向一个方向运动|
|负方向超过阈值|两台电机同步向相反方向运动|
|中心区域|保持当前位置目标|

因此S2在B=1和B=3下都有效。

## 7.2 当前限制

- 升降传感器上下限逻辑当前被禁用。
- 当前主要依靠编码器目标范围限制。
- ID5和ID6分别保存上电后的初始编码器位置。
- B=2产生的独立偏移会一直保留。

# 八、夹爪控制

夹爪包含：

- M3508 ID7：纵向旋转。
- DM4310：平面旋转。

## 8.1 DM4310平面位置

B不等于3时，切换F设置目标：

|F位置|DM4310目标|
|---|---|
|F=1|-1.94 rad|
|F=2|1.18 rad|
|F=3|3.50 rad|

目标以每10 ms最多0.03 rad的速度逐步变化。

进入B=3后F控制暂停；离开B=3后，如果F没有再次变化，可能继续保持之前的DM4310目标。

## 8.2 M3508纵向旋转

B不等于3时：

- S1正/负方向控制ID7目标增加或减少。
- S1绝对值超过约400才动作。
- C从其他位置切入位置2时，触发一次自动对接：
    - ID7移动到编码器目标50350。
    - DM4310目标同时设置为位置2。
- C离开位置2会取消尚未完成的ID7自动移动。
- 自动移动期间S1被忽略，结束或取消后恢复手动控制。

上电收到ID7反馈后，夹爪首先自动回到编码器位置1558，回位完成前不响应普通S1控制。

# 九、E开关、吸盘和PE1

一般辅助控制主要在B=1且未进入C=3特殊分支时有效：

|E位置|A按键|D按键|
|---|---|---|
|E=1|打开吸盘PE3|关闭吸盘PE3|
|E=2|无动作|无动作|
|E=3|PE1置位|PE1复位|

控制分支优先级：

1. `B=1、C=3、F≠2`：UART4 Code12发送，A/D/E不执行。
2. `B=2`：UART5通信，A/D/E普通功能不执行。
3. `B=1、F=2、C=3`：特殊吸盘直控，不考虑E。
4. 其他B=1组合：使用E普通规则。
5. B=3：吸盘由机械臂逻辑控制。

# 十、Code12控制

## 10.1 RadioMaster工具操作

遥控器脚本为：

```
/SCRIPTS/TOOLS/code12.lua
```

模型混控：

|通道|Source|Weight|
|---|---|---|
|CH13|MAX|GV1|
|CH14|MAX|GV2|
|CH15|MAX|GV3|
|CH16|MAX|GV4|

工具操作：

|操作|功能|
|---|---|
|B置中|允许滚轮编辑|
|滚轮旋转|修改当前数字|
|滚轮短按|下一位|
|A|上一位|
|D|更新发送触发|
|滚轮长按|更新发送触发|
|RTN|退出|

Lua界面显示数字1～4，但打包时会减1，因此MCU内部以及UART输出的实际数字为0～3。

## 10.2 UART5 ASCII发送

步骤：

1. B置于位置2。
2. 在Code12工具中编辑。
3. 按D。
4. MCU从UART5发送12个ASCII数字和换行。

A按键发送：

```
clear\n
```

## 10.3 UART4红外发送

步骤：

1. 准备好Code12。
2. B置1。
3. F置1或3。
4. 将C切入位置3。
5. 进入组合时发送一次16字节二进制帧。

前3字节各打包4个2 bit数字，其余13字节为0。

## 10.4 当前Code12限制

- CH16触发只更新内部 `code12_update_flag`。
- 当前没有任何任务读取该标志。
- 因此滚轮长按本身不会触发UART4或UART5发送。
- UART5发送依赖B=2下按D。
- UART4发送依赖进入 `B=1、C=3、F≠2`。
- Lua脚本即使在B不居中时仍会扫描A/D，所以建议只在B=2下编辑和发送，避免A/D同时触发机器人动作。

# 十一、推荐操作流程

## 底盘

1. B置1。
2. S1、S2回中，确认C没有选择特殊功能。
3. 左摇杆控制平移，右摇杆X控制旋转。
4. 停车时摇杆全部回中，等待停车位置保持。

## 机械臂手动控制

1. A、D释放，S2回中。
2. B置3。
3. 右X控制底座、左Y控制肩部、右Y控制肘部。
4. 需要取消自动路径时推动任一机械臂摇杆。

## 自动吸取和回收

1. B置3。
2. F置3。
3. C选择高度。
4. 按一下A执行吸取。
5. 按一下D执行回收并在结束后关闭吸盘。

## 对接和递出

1. B置3、F置2、C置2。
2. 按A执行对接吸取。
3. 按D执行递出。
4. 递出路径不会自动关闭吸盘，需要另外执行关闭操作。

## Code12发送

1. 打开遥控器Code12工具。
2. B置2并编辑数字。
3. 按D通过UART5发送。
4. 如需UART4红外发送，切换到B=1、F≠2，再把C切入位置3。
